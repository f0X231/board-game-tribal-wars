นี่คือคำอธิบายความหมายของคอลัมน์ทั้งหมดในไฟล์ข้อมูลการเล่น Tribal Wars แบ่งตามหมวดหมู่เพื่อให้เข้าใจง่ายและนำไปใช้วิเคราะห์ต่อได้สะดวกครับ
(หมายเหตุสำคัญจากข้อมูลที่เห็นในไฟล์: ในแมตช์นี้คอลัมน์ fallback มีค่าเป็น 1 และ reasoning ระบุว่า groq API error 404 / 400 แปลว่าชื่อโมเดล llama-3.3-70b-versatile หรือ mixtral-8x7b-32768 ในโค้ดอาจจะเรียกผิด Endpoint หรือถูกยกเลิกบน Groq ระบบจึงสลับมาใช้บอท offline:heuristic เดินแทนให้โดยอัตโนมัติครับ)

หมวดที่ 1: ข้อมูลพื้นฐานของแมตช์ (Match Metadata)
• match_id: รหัสประจำแมตช์ (เช่น m-20261121-073342-4nnt7p) ใช้แยกแต่ละเกมออกจากกัน
• source: แหล่งที่มาของการเล่น (client = เล่นผ่านหน้าเว็บ, experiment = รันทดสอบผ่านคำสั่ง Terminal)
• board_size: ขนาดกระดาน (6, 10, หรือ 12)
• player_count: จำนวนผู้เล่นทั้งหมดในแมตช์ (2, 3, หรือ 4 เผ่า)
• pieces_per_player: จำนวนตัวหมากเริ่มต้นของแต่ละเผ่า
• placement_mode: โหมดการวางหมากเริ่มต้น (MANUAL = ผลัดกันวางแบบ Snake Draft, RANDOM = สุ่มวาง)
• winner: ผู้ชนะในแมตช์นี้ (P1, P2, P3, หรือ P4)

หมวดที่ 2: ลำดับเหตุการณ์และผู้ตัดสินใจ (Event & Decision Info)
• seq: ลำดับเหตุการณ์ทั้งหมดตั้งแต่เริ่มเกม (เริ่มนับจาก 0 ไปจนจบเกม ทั้งช่วงวางหมากและช่วงต่อสู้)
• phase: ช่วงของเกม (PLACEMENT = ช่วงวางหมากเริ่มต้น, PLAYING = ช่วงเดินและยิงศรไฟ)
• kind: ประเภทของการกระทำ (placement = วางหมาก, move = เดินและยิงศรไฟ)
• placement_number: ลำดับการวางหมากตัวที่เท่าไหร่ (มีค่าเฉพาะช่วง PLACEMENT เช่น 1 ถึง 12)
• turn_number: ลำดับเทิร์นการต่อสู้ที่เท่าไหร่ (มีค่าเฉพาะช่วง PLAYING เริ่มนับจาก 1)
• player: เผ่าที่กำลังเล่นในตานั้น (P1, P2, P3, P4)
• piece_id: รหัสประจำตัวของหมากที่ถูกเลือกใช้ (เช่น P1_1 คือหมากตัวที่ 1 ของเผ่า P1)
• controller: ผู้ควบคุมที่ถูกตั้งค่าไว้ (เช่น human หรือชื่อโมเดล AI อย่าง groq:llama-3.3-70b-versatile)
• model_used: โมเดลหรือบอทที่ตัดสินใจจริงในตานั้น (หาก AI หลัก Error จะแสดงชื่อตัวสำรอง เช่น offline:heuristic)
• fallback: บอกว่าเกิดการสลับไปใช้บอทสำรองหรือไม่ (0 = ปกติ, 1 = เกิด Error แล้วใช้ตัวสำรองแทน)
• think_time_ms: เวลาที่ใช้ในการคิดตัดสินใจในตานั้น (หน่วยเป็นมิลลิวินาที)
• reasoning: คำอธิบายเหตุผลเชิงกลยุทธ์ของ AI (หรือข้อความแจ้ง Error หากเกิด Fallback)

หมวดที่ 3: พิกัดการเดิน ระยะทาง และทิศทาง (Coordinates & Kinematics)
• notation: รหัสบันทึกตาเดินแบบมาตรฐาน (เช่น k6-h6/i6 หมายถึง เดินจาก k6 ไป h6 และยิงศรไฟไปที่ i6)
• from: ช่องเริ่มต้นก่อนเดิน (ซึ่งจะกลายเป็นรอยไฟถาวรทันที)
• to: ช่องปลายทางที่เดินไปหยุด (หรือช่องที่วางหมากในเฟส PLACEMENT)
• shoot: ช่องเป้าหมายที่ยิงศรไฟไปปัก
• move_distance: จำนวนช่องที่เดินในตานั้น
• move_direction: ทิศทางที่เดิน (N, S, E, W, NE, NW, SE, SW)
• shoot_distance: จำนวนช่องที่ลูกศรไฟพุ่งออกไป
• shoot_direction: ทิศทางที่ยิงลูกศรไฟ
• distance_from_center: ระยะห่างแบบเส้นตรง (Euclidean Distance) จากจุดกึ่งกลางกระดานไปยังตำแหน่งปลายทาง (to)

หมวดที่ 4: ตัวชี้วัดทางเลือกและความคล่องตัว (Mobility & Branching Metrics)

• branching_factor: จำนวนทางเลือกทั้งหมดที่ผู้เล่นมีให้ตัดสินใจในตานั้น
• total_valid_actions_before: จำนวนรูปแบบการเดิน+ยิงที่ถูกกติกาทั้งหมดของผู้เล่น ก่อน เริ่มตานี้
• player_mobility_after: จำนวนรูปแบบการเดิน+ยิงที่ถูกกติกาของผู้เล่น หลัง จบตานี้
• opponents_mobility_before: ผลรวมจำนวนทางเลือกที่ถูกกติกาของคู่แข่งทั้งหมด ก่อน ตานี้
• opponents_mobility_after: ผลรวมจำนวนทางเลือกที่ถูกกติกาของคู่แข่งทั้งหมด หลัง ตานี้
• opponents_mobility_delta: ค่าความเปลี่ยนแปลงทางเลือกของคู่แข่ง (หลัง - ก่อน) ยิ่งติดลบเยอะ แปลว่าตานี้บีบพื้นที่และตัดทางเดินคู่แข่งได้หนักมาก
• eliminated: ชื่อเผ่าที่ถูกบล็อกจนตกรอบในตานี้ (หากไม่มีจะเว้นว่างไว้)
• next_player: เผ่าที่จะได้เล่นในลำดับถัดไป

หมวดที่ 5: สภาพกระดานโดยรวม (Global Board State)
• empty_cells: จำนวนช่องว่างที่เหลืออยู่บนกระดาน
• fire_tile_count: จำนวนช่องไฟทั้งหมดที่เกิดขึ้นบนกระดานแล้ว
• fire_coverage_ratio: สัดส่วนพื้นที่ไฟเทียบกับขนาดกระดานทั้งหมด (เช่น 0.5 = ไฟไหม้ไปแล้ว 50% ของกระดาน)
• queen_contested_cells: จำนวนช่องว่างที่ผู้เล่นตั้งแต่ 2 เผ่าขึ้นไปสามารถเดินแบบควีนไปถึงได้ในจำนวนก้าวที่เท่ากัน (พื้นที่ปะทะ)
• king_contested_cells: จำนวนช่องว่างที่มีระยะเดินทีละ 1 ช่อง (แบบคิง) เท่ากันระหว่าง 2 เผ่าขึ้นไป
• neutral_cells: จำนวนช่องว่างปิดตายที่ไม่มีหมากตัวใดบนกระดานสามารถเดินเข้าไปถึงได้อีกแล้ว

หมวดที่ 6: สถิติเชิงลึกแยกตามเผ่า (p1_... ถึง p4_...)
ชุดคอลัมน์นี้จะมี 10 คอลัมน์ซ้ำกันสำหรับทุกเผ่า (p1_, p2_, p3_, p4_) เพื่อใช้เปรียบเทียบความได้เปรียบเสียเปรียบรายบุคคล (หากเล่น 2 เผ่า คอลัมน์ของ p3 และ p4 จะเป็นค่าว่าง):
• pX_active: สถานะการอยู่รอด (1 = ยังอยู่ในเกม, 0 = ตกรอบแล้ว)
• pX_pieces: จำนวนหมากทั้งหมดของเผ่านี้บนกระดาน
• pX_active_pieces: จำนวนหมากที่ยังขยับและยิงได้จริง
• pX_trapped_pieces: จำนวนหมากที่โดนขังตายแล้ว (ขยับหรือยิงไม่ได้)
• pX_legal_actions: จำนวนตาเดิน+ยิงทั้งหมดที่เผ่านี้ทำได้ในขณะนั้น
• pX_queen_voronoi: ค่าสำคัญ จำนวนช่องว่างที่เผ่านี้เดินแบบควีนไปถึงได้ เร็วกว่า ทุกเผ่าอื่น
• pX_king_voronoi: จำนวนช่องว่างที่เผ่านี้เดินแบบทีละช่อง (King) ไปถึงได้ เร็วกว่า ทุกเผ่าอื่น
• pX_contested: จำนวนช่องว่างที่เผ่านี้มีระยะก้าวแบบควีนเสมอกับเผ่าอื่น
• pX_king_contested: จำนวนช่องว่างที่เผ่านี้มีระยะก้าวแบบคิงเสมอกับเผ่าอื่น
• pX_exclusive_safe: ค่าชี้วัดผู้ชนะ จำนวนช่องว่างในพื้นที่ปิดตายที่มี เฉพาะเผ่านี้เท่านั้น ที่เข้าถึงได้ (ศัตรูไม่มีทางเข้ามาแย่งได้แล้ว)
